# PasarLokal — Frontend (Proyek E‑Commerce)

Deskripsi singkat proyek frontend PasarLokal untuk tugas Mata Kuliah Aplikasi Berbasis Web. Ini adalah frontend statis berbasis HTML/CSS (Tailwind) dan Vanilla JavaScript yang berkomunikasi dengan backend melalui REST API.

**Teknologi:**
- **Markup:** HTML5
- **Styling:** Tailwind CSS (CDN)
- **JavaScript:** Vanilla JS (Fetch API)
- **Auth storage:** localStorage (JWT)

**Cara Menjalankan (Development):**
- Buka `index.html` di browser atau jalankan web server lokal seperti `Live Server` di VS Code.

**Struktur Proyek (ringkasan):**
- **`index.html`**: Landing page
- **`auth/`**: halaman `login.html`, `register.html`
- **`buyer/`**: halaman buyer (catalog, product-detail, cart, checkout, orders, profile)
- **`seller/`**: halaman seller (dashboard, products, orders, profile)
- **`assets/js`**: `api.js`, `auth.js`, `utils.js` (fungsi fetch, auth, helper)

**Catatan penting:**
- Jangan commit file sementara seperti `_tmp_*.js` — sudah ditambahkan ke `.gitignore`.
